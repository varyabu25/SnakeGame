## 1. Цель работы
Закрепить использование массивов (векторов), циклов, условий и пользовательских функций. Реализовать базовую игру и вариант с ограничением ходов и бонусами.

## 2. Задача и правила
Поле 10×10. Змейка длиной 1 начинает в центре (5, 5). Еда случайно появляется на свободной клетке, увеличивает длину и счёт на 1. Столкновение со стеной или телом — проигрыш. Заполнение поля — победа.

Управление: стрелки или WASD (без Enter). Змейка движется автоматически. Ход — смена направления. В режиме «На время» игра длится не более n ходов. После каждой 10-й смены направления появляется бонус (+3 очка), который сгорает через 3 хода.

## 3. Среда и сборка
Целевая среда — VS Code + WSL, компилятор g++, стандарт C++17. Сборка осуществляется через CMake.
Команды для сборки и запуска:

mkdir build && cd build
cmake ..
cmake --build .
./snake_app

## 4. Структура проекта
include/game.h — заголовочный файл с объявлениями функций и структур.

src/game.cpp — реализация игровой логики.

src/main.cpp — точка входа, игровой цикл и обработка ввода.

tests/test_snake.cpp — модульные тесты для проверки логики.

CMakeLists.txt — файл сборки.

.clang-format — настройки форматирования кода.

docs/REPORT.md — данный отчет.

## 5. Основные функции
init_game — инициализация игры, расстановка змейки.

spawn_food — генерация еды на свободной клетке.

print_field — отрисовка игрового поля.

process_input — обработка нажатий клавиш.

move_snake — логика движения, проверка столкновений и поедания еды.

## 6. Проверка
