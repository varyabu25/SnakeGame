# Проект: Игра «Змейка» на C++

## Описание задачи
Реализация базовой игры «Змейка» (поле 10x10) и творческого варианта «На время» (с бонусами и лимитом ходов).

## Инструкция по сборке и запуску
1. Создайте папку сборки: `mkdir build && cd build`
2. Сгенерируйте файлы сборки: `cmake ..`
3. Соберите проект: `cmake --build .`
4. Запустите игру: `./snake_app`

## Способ обработки ошибок
В проекте используется подход «Код возврата / Значение-маркер» (проверка выхода за границы поля и столкновения возвращает флаг `is_game_over = true`).

## Реализованные подзадачи и функции
* `init_game` — инициализация игры, расстановка змейки.
* `spawn_food` — генерация еды на свободной клетке.
* get_field_string — формирование строки для отрисовки игрового поля.
* `process_input` — обработка нажатий клавиш (WASD/стрелки).
* `move_snake` — логика движения, проверка столкновений и поедания еды.


## Проверяемые сценарии (Тесты)
1. Движение змейки в заданном направлении.
2. Поедание еды и увеличение длины/счета.
3. Столкновение со стеной (проигрыш).
(Тесты находятся в `tests/test_snake.cpp`).
